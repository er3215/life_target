# 人生成就與里程碑日誌

這是一個用純 HTML + JavaScript 製作的個人生命里程碑與人生進度追蹤頁面。使用者可以設定生日、定義人生中的關鍵成就，並以可視化方式檢視自己已經走過多少年、剩餘多少週，以及未來每個歲數的主要目標。

## 專案目的

這個專案的核心概念是把「人生」轉成一張可以持續檢視的視覺化地圖：

- 以 80 歲為整個人生時間軸
- 記錄每個年齡的成就目標
- 顯示目前已經度過的週數與人生進度
- 讓未來的歲月變成一個持續提醒自己的里程碑清單

## 主要功能

- 設定生日並自動計算已度過週數
- 顯示人生進度（以 80 歲為總長度）
- 新增、編輯、刪除成就目標
- 未來歲月以年份膠囊顯示，並顯示該年最主要的目標
- 若同一年有多個目標，會顯示主目標與其附加數量
- 點擊未來年份可展開該年詳細目標資訊
- 支援匯出設定與匯入設定，方便備份與還原資料
- 資料保存在瀏覽器 localStorage 中

## 使用方式

1. 直接開啟 `index.html`
2. 選擇你的生日
3. 在「新增成就目標」區塊填入目標名稱與預計達成歲數
4. 按下「加入目標」
5. 可透過「編輯成就」模式刪除目標
6. 點選未來年份可查看該年目標的詳細內容

## 數據說明

頁面上主要顯示以下資訊：

- 已度過週數：目前距離生日之後已經經過的週數
- 還有幾週：從 80 年總週數中扣除已度過週數後，剩餘多少週
- 人生進度：目前人生進度百分比（至 80 歲）

## 匯出 / 匯入設定

### 匯出設定

- 點擊頁面上方的「匯出設定」按鈕
- 會下載一個 `life-target-settings.json` 檔案
- 檔案內容包含：
  - 生日
  - 目標列表
  - 匯出時間

### 匯入設定

- 點擊「匯入設定」
- 選擇先前匯出的 JSON 檔案
- 系統會自動載入生日與目標設定

> 建議定期匯出備份，以免瀏覽器資料清除或切換裝置後遺失設定。

## 資料儲存

目前資料儲存在瀏覽器的 `localStorage`，因此：

- 同一個瀏覽器／同一台裝置上可持續保留資料
- 若清除瀏覽器資料，則需要重新匯入設定
- 若需跨設備同步，建議定期匯出 JSON 檔案備份
